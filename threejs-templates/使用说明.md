## VSCode 三步跑起来

1. 装 **Live Server** 插件（扩展商店搜索 Live Server，作者 Ritwick Dey）
2. 用 VSCode 打开本文件夹，在 html 文件上**右键 → Open with Live Server**
3. 浏览器自动打开，改代码保存后页面自动刷新

> **为什么不能双击直接打开 html？（详细版）**
>
> 双击打开时，地址栏开头是 `file:///D:/...`，这叫 `file://` 协议。出于安全考虑，浏览器把这种方式打开的网页视为"不可信任的本地文件"：一个网页如果能随意读取你硬盘上的其他文件，就能把你的照片、密码偷偷发出去。所以浏览器规定——**file:// 打开的网页，不允许再调用硬盘上的其他文件**（防止偷读），也不允许跨文件校验身份（防止冒充）。
>
> 而我们的模板用了 ES Module（`import` 导入 three.js），浏览器要"去硬盘上再拿一个 js 文件回来"，正好撞上这条禁令。按 F12 打开控制台会看到红色报错：`Access to script at 'file:///...' from origin 'null' has been blocked by CORS policy`——这就是被拦了。
>
> Live Server 干的事：在你的电脑上临时开一个**迷你网站**（地址变成 `http://127.0.0.1:5500`，127.0.0.1 就是"本机自己"）。网页从网站来，身份正常，浏览器就放行了。
>
> 一句话给学生：**双击 = 在家门口摆摊，城管（浏览器）不让进货；Live Server = 帮你开了家正规小店，进货随便。** 顺便说，如果哪份代码双击能打开，说明它没用 `import`（老式写法），不是我们的模板。

## 网络与 CDN：要 VPN 吗？

> **更新：所有模板（00~03、游戏 A/B、离线版）的 importmap 已全部改为本地 `./libs/` 路径，默认即离线可用，本节留作背景知识。** 唯一前提：仍需用 Live Server 打开（`file://` 限制与联网无关）。

**结论：一般不用 VPN。unpkg 在国内时快时慢——现在模板已不依赖它。**

- unpkg.com 在国内没有服务器，多数时候能连上但慢，偶尔超时——表现就是白屏，等一会儿或刷新又好了。这不是被墙，是"远"。
- **jsdelivr（cdn.jsdelivr.net）**：全球 CDN，国内多数网络可直连，速度明显更好。机房第一次课**建议提前换好**：

```
"three": "https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js",
"three/addons/": "https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/"
```

- 如果学校网络连 jsdelivr 也不稳，换 npmmirror（淘宝镜像，国内服务器）：

```
"three": "https://registry.npmmirror.com/three/0.160.0/files/build/three.module.js",
"three/addons/": "https://registry.npmmirror.com/three/0.160.0/files/examples/jsm/"
```

- **彻底断网的保底方案：离线包已经做好了**（见文件清单里的 `离线版-入门演示.html`）。库文件全在本文件夹内：

```
libs/
  three.module.js                  ← three.js 本体（约 1.2MB）
  jsm/controls/OrbitControls.js   ← 轨道控制器
  jsm/loaders/GLTFLoader.js       ← 模型加载器
  jsm/utils/BufferGeometryUtils.js ← GLTFLoader 的依赖
  jsm/libs/lil-gui.module.min.js  ← 参数面板
models/
  Flamingo.glb                    ← 官方示例"火烈鸟"，自带飞行动画
```

  离线版模板的 importmap 指向 `./libs/...` 本地路径，**断网、CDN 被墙、机房网络炸了都照跑**。
  想把其他模板（00/01/02/游戏 A/B）也改成离线：把模板里 importmap 的两行网址换成下面这两行即可——

```
"three": "./libs/three.module.js",
"three/addons/": "./libs/jsm/"
```

  拷贝给其他老师/学生时，**整个文件夹一起拷**（html + libs + models），只拷 html 会白屏。
  两个前提：① 仍然要用 Live Server 打开，不能双击（离线 ≠ 免服务器，`file://` 限制还在）；② 以后想升级 three 版本，重新下载对应版本的这 5 个文件覆盖即可。
- **判断技巧**：白屏时按 F12 看控制台——报 `Failed to fetch` / `net::ERR_...` 是网络问题（换上面任一地址）；报其他红字才是代码问题。

## 下载好的模型怎么用（VSCode 完整流程）

**第一步：放文件（1 分钟）**

1. 在模板文件夹里新建 `models` 文件夹（和 html 文件平级）
2. 把下载的 `.glb` 文件拖进 VSCode 左侧边栏的 `models` 文件夹（或直接在资源管理器里复制进去）
3. **文件名改成英文、不含空格**：`恐龙.glb` → `dinosaur.glb`。中文文件名在浏览器编码转换时可能出幺蛾子，这是最不值当又最常见的坑

**第二步：改一行代码（30 秒）**

打开 `03-加载模型.html`，找到 `loader.load(` 后面的模型路径，改成你的文件：

```js
const MODEL_URL = 'models/dinosaur.glb';   // 相对路径：从 html 文件出发找
```

**第三步：Live Server 打开看效果**

html 上右键 → Open with Live Server。模型忽大忽小不用管——03 模板会自动量尺寸、统一高度、贴地摆好。

**注意事项（学生高频翻车点）：**

| 坑 | 说明 |
|------|------|
| 下载 `.gltf` 而不是 `.glb` | `.gltf` 通常附带一个 `.bin` 文件和一个贴图文件夹，**三个要整套放、相对位置不能变**。嫌麻烦就在下载时选 `.glb`（全部打包成一个文件） |
| 模型不出现 + 控制台 404 | 九成是路径打错。按 F12 → Network 面板 → 刷新，看红色那行的路径，和实际文件夹对照 |
| FBX/OBJ 模型变白/变灰 | 这两种格式贴图经常丢。优先下 GLB；实在要 FBX，把贴图文件放同目录再看 |
| **模型成"白膜"（灰白一片）** | 两种原因：① **缺环境光**——现在的主流模型用 PBR 材质，靠反射环境显色，没有环境光就是灰白的。03 模板已内置 `RoomEnvironment` 环境光（代码生成，离线可用），自带修好。② **旧版材质规范**——部分老模型（尤其 Sketchfab 上 2018-2021 年的）用 `KHR_materials_pbrSpecularGlossiness` 旧扩展，three.js 新版已不再支持，表现是"网站上好看、本地白膜"。解法：用 gltf-transform 转一次格式：`npx @gltf-transform/cli metalrough 原模型.glb 新模型.glb`（一次性转换，永久解决）。models/ 里的 `scifi_girl_v.01_mr.glb` 就是这么转出来的 |
| 模型巨卡 | 面数太高（几十万三角形）。下载前先拖进 threejs.org/editor 看左下角统计 |
| 带动画的模型不动 | 加载动画需要在代码里 `mixer = new THREE.AnimationMixer(model)` 播放，模板没带这段，要加就问 AI："帮我给这个 GLB 加上动画播放" |
| 同学拷走打不开 | 模型文件在 `models/` 里，拷贝要拷**整个文件夹**，不是只拷 html |

## 模型格式转换工具：gltf-transform 在哪里找

模型白膜（材质用了旧规范）需要转换时，用的是 **gltf-transform**（Don McCurdy 维护的开源命令行工具，和 three.js 生态同源）：

**方式一：本机安装（推荐，一劳永逸）**

1. 先装 Node.js（nodejs.org 下载 LTS 版装上；国内慢就用镜像 npmmirror.com）
2. 在 VSCode 顶栏菜单 Terminal 打开终端，执行一次：
   ```
   npm install --global @gltf-transform/cli --registry=https://registry.npmmirror.com
   ```
3. 以后任何模型转换只需一行（把文件拖进终端自动补全路径）：
   ```
   gltf-transform metalrough 原模型.glb 新模型.glb
   ```
   顺带还能瘦身：`gltf-transform optimize 大模型.glb 小模型.glb --texture-compress webp`

**方式二：不装任何东西（偶尔用一次）**

- 直接把模型发给 AI 助手（如 WorkBuddy）说"帮我转成 metal/rough"，后台会用同一工具处理
- 在线检查模型内部构造（材质/贴图/面数统计）：**gltf.report**——把 GLB 拖进网页即可，纯本地解析不上传

**在线验货工具（判断白膜原因用）**

- **threejs.org/editor**：和我们的模板同一引擎。模型拖进去若白膜 → three.js 里也会白膜；有贴图 → 模板里也会正常
- **sandbox.babylonjs.com**（Babylon 沙盒）：支持旧材质规范。模型在它这里正常、在 three.js editor 里白膜 = 100% 确认是旧规范，转换即可


## 常见坑（学生必踩，提前打好预防针）

| 现象 | 原因 |
|------|------|
| 画面全黑 | 九成是没加灯光，或相机在物体内部 |
| 白屏报错 `Failed to resolve module` | importmap 没放在 `<script type="module">` 前面，或没联网 |
| 打开是源代码 | 用了 `file://` 直接双击打开，要用 Live Server |
| 物体不显示 | 相机太远/太近，或物体在相机身后 |
| 改了没反应 | 顶点数据改完没写 `pos.needsUpdate = true` |

## 教学心法

- 不讲 3D 数学，先讲类比：**场景=舞台，相机=摄影师，渲染器=放映机**
- 所有"数学"只出现 `sin` 一个函数（波浪、弹跳都是它）
- 让学生从**改数字**开始，而不是从写代码开始——GUI 面板就是这个目的
- 建模不是前置条件：几何体拼装 + 现成 GLTF 模型 + 代码生成（波浪、粒子）就够了
